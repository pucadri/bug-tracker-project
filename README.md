## 📌 Project Overview

Bug Tracker Software is a web-based application designed to simplify the process of reporting, managing, and tracking software bugs and issues.

The system provides a centralized platform where users can register, log in, and report software-related issues. It aims to make bug management more organized and efficient through an easy-to-use interface and database integration.

This project was developed to demonstrate practical knowledge of web development, backend programming, and database management.

## ✨ Features

- User Registration
- User Login and Authentication
- Bug and Issue Reporting
- Bug Description and Issue Details
- User-Friendly Interface
- Database Integration
- Organized Project Structure

## ⚙️ Installation and Setup

Follow these steps to run the project on your local machine.

### Prerequisites

- XAMPP or a compatible PHP development environment
- MySQL Database
- Web Browser
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/pucadri/bug-tracker-project.git
```

### 2. Navigate to the Project Directory

Move the downloaded project into the XAMPP `htdocs` directory.

```text
C:/xampp/htdocs/bug-tracker-project/
```

### 3. Start Apache and MySQL

1. Open XAMPP Control Panel.
2. Start Apache.
3. Start MySQL.

### 4. Configure the Database

1. Open phpMyAdmin.
2. Create a new database.
3. Import the SQL database file from the `sql/` directory.
4. Configure the database connection details in the relevant PHP configuration file.

### 5. Run the Application

Open your browser and visit:

```text
http://localhost/bug-tracker-project/
```
